# 🎯 Adivina el Número - Vite 

## 📖 Descripción del Proyecto

Un juego interactivo de adivinanza desarrollado con **Vite** y **Vanilla JavaScript**. El objetivo es adivinar un número secreto entre 1 y 100 con un máximo de 10 intentos. La aplicación utiliza Vite como herramienta de construcción moderna para desarrollo rápido y optimización de bundling.

## ✨ Características

- 🎲 Número aleatorio entre 1 y 100
- 📊 Contador de intentos
- 🏆 Mejor racha guardada en localStorage
- 📜 Historial de intentos
- 💡 Sistema de pistas
- 🎨 Diseño moderno y responsive
- ⚡ Validación en tiempo real
